# Eval: report-basic

Prompt:

```text
请生成一份关于上半年工作情况的报告，发文机关是XX局，主送机关是市政府。内容包括主要做法、取得成效、存在问题和下一步工作安排。不要写成请示。
```

Expected:

- Identifies document type as report.
- Uses report structure.
- Does not use `妥否，请批示。`
- Includes major work, achievements, problems, and next steps.
- Uses formal reporting tone.
