# Eval: notice-basic

Prompt:

```text
请帮我生成一份关于开展安全生产检查的通知。发文机关是XX市应急管理局，主送机关是各区县应急管理局。内容包括检查时间为2026年7月1日至7月15日，检查范围为重点工贸企业，要求各单位做好自查、现场检查和问题整改。
```

Expected:

- Identifies document type as notice.
- Includes title, recipient, body, signature, date.
- Uses a notice-appropriate ending such as `特此通知。`
- Can generate DOCX if requested.
- Uses formal official tone.
