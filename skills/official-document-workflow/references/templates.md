# 公文模板骨架

These are skeletons, not fixed outputs. Adapt to the user's facts and document type.

## 通知

```markdown
# 关于开展XX工作的通知

各有关单位：

为XX，现就有关事项通知如下。

## 一、总体要求

[说明工作目标、原则和背景。]

## 二、主要内容

[说明时间、范围、对象、安排。]

## 三、工作要求

[提出组织、落实、反馈等要求。]

特此通知。

XX单位
2026年X月X日
```

```markdown
[概述背景和总体情况。]

[列明做法、成果、数据。]

## 三、存在问题

[客观说明问题和原因。]

## 四、下一步工作安排

[提出后续计划。]

XX单位
2026年X月X日
```
