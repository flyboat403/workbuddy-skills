# 公文专家团检查清单

## Task fit

- [ ] Task mode is identified: create / revise / format-only / audit.
- [ ] Document type is identified.
- [ ] Required core elements are present or missing fields are reported.
- [ ] User assumptions are stated.

## Document type

- [ ] Structure matches the document type.
- [ ] Ending phrase matches the document type.
- [ ] Request documents contain one clear request.
- [ ] Reports do not use request-style endings.

## Content integrity

- [ ] Key facts from the user are preserved.
- [ ] Key figures and dates are preserved.
- [ ] Unsupported claims are marked for confirmation.
- [ ] Revision tasks preserve independent substantive points.
- [ ] Problems and corresponding measures are not accidentally separated or deleted.

## Positioning

Verify against `references/drafting-positions.md` (single source for 谋篇四定).

- [ ] Narrative (定叙事): opening suits the audience; upward-reporting materials lead with a horizontal, current-state overview, with the timeline only as support.
- [ ] Policy mainline (定主线): content aligns with the latest higher-level policy requirements and wording; the policy mainline leads the material.
- [ ] Authority boundary (定边界): wording stays inside the issuing unit's role; supporting units (配合部门) do not make whole-system evaluations.
- [ ] Voice (定语态): in multi-role documents (主持词、致辞、讲话), opening and stance differ by identity; no shared boilerplate.

## Language and tone

- [ ] Tone is formal, accurate, concise, and plain.
- [ ] No colloquial phrasing.
- [ ] Headings are concrete and preferably conclusion-led.
- [ ] Dates, punctuation, and document numbers are standardized.
- [ ] No excessive empty slogans.

## Format

- [ ] A4 page.
- [ ] Margins: top 37mm, bottom 35mm, left 28mm, right 26mm.
- [ ] Body font: 仿宋_GB2312 or acceptable fallback.
- [ ] Body size: about 16pt.
- [ ] Line spacing: fixed 28pt.
- [ ] Body first-line indent: 2 Chinese characters.
- [ ] Title centered, about 22pt.
- [ ] Heading hierarchy uses 一、 （一） 1. （1）.

## File output

- [ ] DOCX file exists when requested.
- [ ] DOCX opens without error.
- [ ] Formatting script completed.
- [ ] Format audit report is generated for final DOCX when required.
