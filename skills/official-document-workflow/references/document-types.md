# 公文文种与任务模式

Use this file to identify document type, required elements, and structure.

## 通知 notice

Use for publishing matters that relevant units should know, implement, or prepare for.

Typical structure:

```text
标题
主送机关：
一、事项背景或目的
二、时间、范围、对象
三、工作要求
落款
日期
```

Common ending:

```text
特此通知。
```

## 报告 report

Use for reporting work, reflecting conditions, or responding to higher-level inquiries.

Typical structure:

```text
标题
主送机关：
一、基本情况
二、主要做法和成效
三、存在问题
四、下一步工作安排
落款
日期
```

Avoid request-style endings such as `妥否，请批示。`

## 请示 request

Use for requesting instructions or approval from a higher-level authority.

Typical structure:

```text
标题
主送机关：
一、请示事项
二、请示理由
三、具体建议或方案
妥否，请批示。
落款
日期
```

Rules:

- Usually one request per document.
- The requested decision should be clear.
- Do not mix multiple unrelated requests.

## 批复 reply

Use to reply to a lower-level request.

Typical structure:

```text
标题
主送机关：
一、对来文的引用
二、批复意见
三、执行要求
落款
日期
```

## 函 letter

Use between non-subordinate institutions for consultation, inquiry, reply, or coordination.

Typical structure:

```text
标题
主送机关：
一、来函或事项背景
二、商洽、询问、答复或协调事项
三、希望对方办理或回复的要求
落款
日期
```

Common ending:

```text
专此函达。
请予函复。
```

## 会议纪要 minutes

Use to record meeting situation and agreed matters.

Typical structure:

```text
标题
一、会议基本情况
二、会议研究事项
三、会议议定事项
四、工作要求
```

## 工作总结 work-summary

Use for summarizing completed work.

Typical structure:

```text
一、基本情况
二、主要做法
三、取得成效
四、存在问题
五、下一步计划
```

## 工作方案 work-plan

Use for arranging future work.

Typical structure:

```text
一、总体要求
二、工作目标
三、重点任务
四、责任分工
五、保障措施
```

## 领导讲话稿 speech

Use for formal meeting speeches or deployment speeches.

Typical structure:

```text
一、提高认识
二、聚焦重点
三、压实责任
四、抓好落实
```

## Mode selection

| User input | Mode |
|---|---|
| asks to write/generate a document | create |
| provides rough source material or old draft | revise |
| provides DOCX/Markdown and asks for formatting | format-only |
| asks whether a draft is compliant | audit |
